# CCAO-F Practice

A self-contained practice app for the **Claude Certified Associate – Foundations (CCAO-F)** exam.

- **Drill mode** — work through questions by domain with instant feedback and rationale.
- **Exam simulator** — a 60-item mock, weighted to the published domain blueprint, 120-minute timer, scaled score with the pass mark at 720/1000.
- **Weak-area report** — per-domain performance, with links to the matching Agent Factory lessons for your weakest domains.

## Use it
Open `index.html` in any browser. No install, no server, no network required — everything is in the one file.

## About the questions
- Original practice questions built to the published CCAO-F blueprint. **Not real exam items.**
- The answer key was independently cross-checked and spot-grounded against the Agent Factory curriculum.
